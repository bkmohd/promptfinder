        03 — The test lab
        
No prompt ships without a test date.

      

      
New models every few weeks. A prompt without a test log is just a rumour.

    

    

      

        
Every prompt in the library is run on current models with the same inputs, scored against one rubric, and re-tested when a model changes. The score you see is the last cycle, not a launch-week screenshot.

        

          

            01
            
Run it ten times, same inputs.
Ten generations per prompt, per model, with identical filled variables. We log the outputs instead of remembering the best one.

          

          

            02
            
Score against one rubric.
Forty points across four criteria: works without edits, follows the format, handles facts safely and sounds like the brief. Pass rate is reported honestly, including the failures.

          

          

            03
            
Re-test monthly, and on every release.
When a new model version ships, the affected prompts go back on the bench. Test dates change; the URL doesn't.
