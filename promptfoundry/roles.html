How this scales

One page per job.
Not one page per keyword.

Prompt content is the most obviously programmatic category in AI search: every role has real tasks, every task has real searches, and every model has different behaviour. That is a legitimate reason to build role × task × model pages — not a reason to publish ten thousand thin ones.

So we keep the quality bar visible. A role page only lists prompts that have cleared a test cycle. Pages without enough tested material stay unpublished until they earn it. Each page carries its own test date, its own model results, and a task matrix that links straight into the Studio with the role pre-filled.

The flywheel: the Studio generates a prompt in seconds → we test the best outputs → the ones that pass become library entries and role pages → those pages send people back into the Studio with better inputs.
