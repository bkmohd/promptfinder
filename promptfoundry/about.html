About

A small lab, not a content farm.

PromptFoundry exists because most prompt libraries are a screenshot and a promise. We wanted the opposite: a library that tells you when it was last checked, what failed, and which model it was actually run on.

What this is

A library of prompts that have cleared a test cycle, a builder that adapts the same structure to six different models, and a grader for the prompts you already use. The library is small on purpose. It grows when a prompt earns its place, not when a keyword tool suggests a page.

What this is not

  • Not a prompt marketplace. Everything here is free to copy and adapt.
  • Not a giant auto-generated list. Role pages only list prompts that have been tested. A page with one honest prompt is better than a page with forty unverified ones.
  • Not affiliated with any model provider. OpenAI, Anthropic, Google, xAI, Midjourney and OpenAI's image models are named because we test them, not because they endorse us.
  • Not neutral about hype. If a prompt's pass rate drops after a model release, the page says so.

How we are funded

The site is currently ad-supported and may use affiliate links to tools we test. Two rules:

  1. Commercial relationships never change a test score. Sponsorships, if they happen, are labelled as sponsorships, and sponsored prompts are excluded from library rankings.
  2. Ads are kept out of the tools. No interstitials in the Studio, no ad units between the prompt and the copy button. Ads, where present, sit between sections — and never inside a prompt.

We would rather sell a clearly labelled newsletter sponsorship than quietly rank a partner's prompt as "most copied".

Who writes this

PromptFoundry is run by a small editorial team that builds and tests prompts daily. The test bench is documented in public: methodology, rubric and changelog. We don't publish invented author bios or fake credentials; if a named editor writes a piece, their name and role appear on it.

Corrections

If a prompt fails for you — especially if it fails on inputs we didn't test — tell us. Send the prompt, the model version and what happened to hello@promptfoundry.example. Reproducible failures become test cases and, where needed, public corrections.

Work with us. We take on a small number of sponsored placements and custom prompt builds (teams that want their own tested library). Both are labelled; neither buys a score. Email hello@promptfoundry.example.
